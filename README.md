# Stundenzettel – Wochenkarte (Dark Mode)

Einfache Zeiterfassung für die Woche im Dark Design. Läuft als PWA direkt im Browser und kann als App am Handy installiert werden.

**Live:** https://v00771.github.io/stundenzettel/

### Features
- Sollstunden einstellbar (z. B. 38,5h)
- Automatische Pausenberechnung: 30 Min. ab >6h
- Modi: Fix, Ende berechnen, Start berechnen
- Gauge mit Netto-Anzeige
- LocalStorage + Offline PWA

### Installation (GitHub Pages)
1. Alle Dateien ins Root hochladen (kein Unterordner)
2. Settings → Pages → Branch main / root → Save
3. Nach 1-2 Min live

### Am Handy installieren (iPhone)
Safari → Teilen → Zum Home-Bildschirm → Hinzufügen

### Nutzung
Start/Ende eintragen, einen Tag auf "Ende berechnen" stellen, 
damit rechnet er Freitag automatisch für 38,5h aus.
